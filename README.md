# 🚗 RDR – Real-time Drowsiness Response System

An AI-powered system designed to detect driver drowsiness in real time using computer vision and IoT technologies.

## 📌 Overview
Driver fatigue is one of the major causes of road accidents worldwide.  
The RDR system monitors the driver’s face, eyes, and blinking patterns to detect signs of drowsiness and alert the driver immediately.

## 🧠 Technologies
- Python
- OpenCV
- Machine Learning
- Flutter
- ESP32
- Computer Vision

## ⚙️ Features
- Real-time face detection
- Eye blink monitoring
- Drowsiness alert system
- Mobile application monitoring
- IoT device integration

## 📱 System Architecture
Camera → AI Model → Drowsiness Detection → Alert System → Mobile App
